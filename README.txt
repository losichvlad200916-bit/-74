АК-74: 3D-разборка и ТТХ (PWA)

Файлы: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.

1. Разместите все файлы в одной папке на любом HTTPS-хостинге
   (GitHub Pages, Netlify, Cloudflare Pages, свой сервер).
   Service worker не работает с file:// и обычным http (кроме localhost).
2. Откройте адрес на телефоне ОДИН РАЗ при интернете: страница и библиотека three.js сохранятся в кэш.
3. Android (Chrome): меню, "Установить приложение" или кнопка "Установить" на странице.
   iPhone (Safari): "Поделиться", "На экран Домой".
4. Дальше приложение открывается офлайн.

Чтобы обновить приложение, измените CACHE ('ak74-v1' в sw.js) на новую версию.
Локальная проверка: python3 -m http.server 8000 в этой папке, затем http://localhost:8000
